Q: How do I connect Chatty with Klaviyo?
Q: The merchant wants to sync customer data to Klaviyo for email marketing.
A: Guide the merchant through Klaviyo integration:

1. Go to Integrations > Klaviyo.
2. Enter the Klaviyo API key (found in Klaviyo > Settings > API Keys).
3. Select which data to sync: contacts, tags, conversation data.
4. Enable the integration.

**Synced data:** Customer email, name, tags, conversation history — useful for targeted email campaigns.

---

Q: The Klaviyo integration is not syncing contacts.
Q: Customer data from Chatty is not appearing in Klaviyo.
A: Check these items:

1. Verify the API key is correct and has write permissions.
2. Check if the integration is enabled in Chatty settings.
3. Syncing may have a delay — wait up to 1 hour for data to appear.
4. If the issue persists, ask the merchant to regenerate the API key in Klaviyo and re-enter it in Chatty.
5. Escalate to TS team if the problem continues.

---

Q: The merchant wants to connect Chatty with Zendesk.
Q: How does the Zendesk integration work?
A: Chatty integrates with Zendesk to create a unified helpdesk experience:

1. Go to Integrations > Zendesk.
2. Follow the connection steps to link the Zendesk account.
3. Conversations from Chatty can be synced to Zendesk as tickets.

For detailed setup, refer to the help center documentation.

---

Q: The merchant is asking about connecting a tool that Chatty doesn't support.
Q: Can Chatty integrate with [unsupported tool]?
A: Currently, Chatty supports integrations with Klaviyo, Zendesk, Joy Loyalty, Air Reviews, and Powerful Contact Form.

**For unsupported integrations:**
1. Check if the requested tool can connect via a webhook or API workaround.
2. If not possible, log the request as a feature request.
3. Share the feedback with the product team for future consideration.
4. Never promise integration timelines — say "I'll pass this feedback to our product team."
