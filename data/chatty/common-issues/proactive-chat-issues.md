Q: How do I set up proactive chat messages for a merchant?
Q: The merchant wants to auto-send a welcome message to visitors.
A: Guide the merchant through proactive chat setup:

1. Go to **Proactive chat** (its own top-level section, not nested under Chatbox) and click **Create proactive chat**.
2. Choose a campaign type (e.g. Welcome visitors) and enter the proactive message text.
3. Set targeting: trigger (page load, scroll percentage, or time delay), which pages, audience, and devices.
4. Set the display duration for how long the campaign stays visible.
5. Check the preview, then click **Activate** to make it live.

**Important:** Proactive chat can bypass the pre-chat form — customers can reply without providing their email first. Inform the merchant of this behavior.

Q: Proactive chat messages are not showing on the store.
Q: The auto-greeting message doesn't appear for visitors.
A: Check these items:

1. **Campaign activated:** Verify the campaign is toggled **Active** under **Proactive chat**.
2. **Trigger conditions:** Make sure the conditions are realistic (e.g., "after 5 seconds on page" not "after 999 seconds").
3. **Display rules:** Check if chatbox display rules are hiding it on certain pages/devices.
4. **App embed:** Ensure Chatty app embed is enabled in theme editor.
5. **Browser cache:** Ask the merchant to test in incognito/private mode.

Q: The merchant wants to show different proactive messages on different pages.
Q: Can I customize the greeting based on which page the customer is on?
A: Yes, proactive chat supports page-specific targeting:

1. Create multiple proactive messages.
2. For each message, set the "Page URL" condition to target specific pages (e.g., product pages, cart page, homepage).
3. Each message can have different text, timing, and frequency.

This is useful for showing product-related help on product pages and cart abandonment messages on the cart page.
